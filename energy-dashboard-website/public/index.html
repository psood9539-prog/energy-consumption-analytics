Project overview

What this project is about

This project turns 60,000 electricity meter readings from 50 consumers in 10 regions (Himachal Pradesh, Chandigarh and Punjab) into a clear, interactive dashboard. The data was taken from Kaggle, cleaned with MySQL Workbench and Google Colab, and is presented here with live charts and written insights.

Question

Where, when and by whom is electricity used, and how is billing spread across consumers?

Data

Meter readings for Residential, Commercial and Industrial consumers, with peak and off-peak units and bills.

Outcome

A filterable dashboard with KPIs and six charts, plus insights calculated directly from the data.

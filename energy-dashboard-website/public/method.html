Energy Consumption Analytics

Data & Method

Where the data came from and how it was prepared.

Data source

Kaggle dataset

The project data comes from a public energy consumption dataset on Kaggle. After cleaning, the working file is clean_data.csv: 60,000 meter readings with 19 columns, covering 1 January 2024 to 31 December 2025, 50 consumers and 10 regions.

Workflow

Cleaning and preprocessing

1. Download from Kaggle

The raw dataset was downloaded from Kaggle as the starting point.

2. Load and prepare in MySQL Workbench

The data was loaded into MySQL Workbench. SQL queries were used to inspect the tables and combine the related information (readings, meters, consumers, regions and tariffs, visible as the ID columns in the final file) into one table.

3. Clean and check in Google Colab

In Google Colab the data was checked with Python for missing values, duplicate rows, data types and date formats, then exported as clean_data.csv.

4. Build the dashboard

The clean file was used to build the dashboard KPIs and charts. This website reads the same file and calculates every figure from it.

Quality checks

Results of the checks on the final file

  • 60,000 rows; every Consumption_ID is unique.
  • No missing values in any column and no duplicate rows.
  • Units_Consumed always equals Peak_Units + OffPeak_Units.
  • Dates use one consistent format (YYYY-MM-DD) and cover 731 days.
  • Each consumer has exactly one consumer type.
Note: tariff slab names are used exactly as they appear in the data. In this file the “201-300 Units” slab holds readings of 301–600 units, the “101-200 Units” slab holds 101–300 and “0-100 Units” holds 50–100.

Metrics

How each number is calculated

  • Units consumed: sum of Units_Consumed.
  • Total bill: sum of Total_Bill.
  • Avg bill per reading: total bill ÷ number of readings.
  • Active consumers: number of different Consumer_IDs in the selection.
  • Peak share: Peak_Units ÷ Units_Consumed.
  • Average cost per unit: total bill ÷ units consumed.

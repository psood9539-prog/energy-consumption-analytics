I am an engineering student with an interest in data analytics. This project brings together data sourcing, cleaning, analysis and visualisation to understand electricity consumption and billing, and presents the results as an interactive website.

What I worked on in this project

  • Sourced the energy consumption dataset from Kaggle.
  • Cleaned and prepared the data using MySQL Workbench and Google Colab.
  • Built a dashboard with KPIs and six charts covering consumption, billing and peak load.
  • Developed this website with a Node.js data API, page filters and a contact form.
